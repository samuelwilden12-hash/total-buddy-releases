# Total Buddy downloads

This repository only holds **Total Buddy release files**: the Windows installer, the Android app and their SHA-256 checksums. Installed copies of Total Buddy check here and update themselves.

**Download:** open the latest release on the right and pick `TotalBuddy-Setup-<version>.exe` (Windows) or `TotalBuddy-<version>-android.apk` (Android).

Releases are built automatically on Total Repo. The source code is private.
